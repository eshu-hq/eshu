# `contracts/upstream/` — generated wire-shape snapshots

Every `*-read-wire-shapes.txt` file in this directory is GENERATED by
`scripts/gen-read-wire-shapes.sh` from the oracle fragments pinned
row-by-row in `contracts/step2-frozen-scope.md` (core oracle
`8a78eb3f48`). **Never hand-edit them.** A deliberate upstream change
regenerates the affected file; an edit that makes a snapshot disagree
with its oracle fragment is a defect, never a fix (per the step-2
scope ruling's contract hierarchy: pins govern, stubs follow).

Regenerate (worktree root): `bash scripts/gen-read-wire-shapes.sh`.
The script fails closed on a missing fragment, a scope-table parse
with zero rows, or a row-count mismatch, and is deterministic
(table order, no timestamps).
