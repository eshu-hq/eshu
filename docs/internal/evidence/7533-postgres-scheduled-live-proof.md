The `postgres-scheduled` runner owns 167 exact named tests in 89 live files. The same job runs daily at 04:35 UTC, on manual dispatch, and for pull requests changing its exact enrolled inputs. It uses one digest-pinned PostgreSQL 18.6 service. Crossplane, infra inventory, ACK/completion, claim, liveness, fanout, search, and readiness each use separate fresh databases. The three disposable groups use an administrative DSN to `postgres`, then the shared test helper creates a random database from template0 and cleans it up. These rows have class `verified_scheduled`; they are no longer counted as legacy scheduled exemptions. The hosted PR job must pass before the enrollment merges; it is not a universally required PR or merge check while its cost probes lack repeated timing evidence. Actual cron delivery has not yet been observed.

## Hosted proof retention

Every hosted attempt writes `manifest.json` with the run URL, ID, attempt, event, reviewed PR head SHA, actual checkout SHA, event SHA, inventory and selected-source checksums, pinned image, and observed PostgreSQL version identity. A final step rechecks that manifest and all eleven Go JSON streams. The workflow uploads them together as a 14-day artifact, including after a failing proof step. The workflow contract pins every executable step, including checkout, Go setup, module prewarm, manifest creation, database bootstrap, proof commands, and bundle verification. Each Go proof step checks staged, unstaged, and untracked source changes under `go/`, `scripts/`, and `.github/workflows/` immediately before its test command and after event validation; it also refuses inherited `GOFLAGS` or `GOWORK`. This binds tested source bytes to the event checkout after module prewarm and between package groups. Before merge, record the passing PR run and artifact URL and verify its reviewed head and checkout SHAs. The local manifest and bundle check used synthetic run metadata with the owned PostgreSQL 18.6 fixture and retained Go streams. Its manifest says `local_simulation`; the hosted verifier rejects that origin, and GitHub Actions forbids the local allowance. This local check is not hosted execution evidence.
