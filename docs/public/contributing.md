# Contributing

The canonical contributing guide lives at [CONTRIBUTING.md](https://github.com/eshu-hq/eshu/blob/main/CONTRIBUTING.md) in the repository root.

It covers:

- PR guidelines and code style rules
- Development setup with `uv sync`
- Required local checks before submitting
- How to submit changes

When you add or revise public documentation, follow the
[Documentation style guide](documentation-style-guide.md). It explains how to
choose a page type, structure the page, and write examples that readers can
copy safely.

For parser-specific contribution rules (adding language or IaC support), see [Contributing Language Support](contributing-language-support.md).

For the developer guide covering the Go parser architecture, fixture-backed
contract pages, compose verification, and runtime boundaries, see
[DEVELOPING.md](https://github.com/eshu-hq/eshu/blob/main/DEVELOPING.md).
