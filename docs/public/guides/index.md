# Guides

These are the task-focused guides that live in this folder. If Eshu is not
running yet, start with
[First successful run](../getting-started/first-successful-run.md). If you
want the shorter job-based paths first, [Use Eshu](../use/index.md) routes
you by goal. This page is the full shelf.

## Ask and explore

- [Starter prompts](starter-prompts.md) — ready-made prompts for your first questions.
- [Relationship graph examples](relationship-graphs.md) — see how linked answers look in practice.
- [Find parallel implementations](code-divergence.md) — spot code that does the same job twice.
- [Visualize query results](visualization.md) — turn answers into pictures you can share.
- [Work with bundles](bundles.md) — package and move indexed data.
- [Trace shared infrastructure](shared-infra-trace.md) — follow one database, queue, or secret to everything that shares it.
