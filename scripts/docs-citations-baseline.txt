# scripts/docs-citations-baseline.txt
#
# Burn-down baseline for scripts/verify-doc-citations.sh (#5406/#6383).
# Every docs/public/languages/*.md page (which already covers
# feature-matrix.md and support-maturity.md) plus
# docs/public/reference/parity-closure-matrix.md is scanned for
# `<file>.go::TestName` and `tests/fixtures/...`/`testdata/...` citations.
# The full go/ and docs/ trees are also scanned for raw
# `go/internal/**/*.go:<line>` citations.
#
# Three record shapes, one per line:
#   TEST <doc-relpath> <cited-file>::<TestName>   - dead/renamed/moved test
#   FIXTURE <fixture-path>                        - fixture that exists but
#                                                   is not referenced by any
#                                                   non-Markdown file in the
#                                                   repo (deduplicated across
#                                                   every citing doc, since
#                                                   fixing the fixture fixes
#                                                   every citing page at once)
#   LINE <source-relpath> <cited-file>:<line>       - raw line recurrence debt;
#                                                   one row per occurrence
#
# A subtest-form TEST citation (`TestName/subtest_case`) is NEVER written
# here — it always fails the gate; cite the parent test function instead.
# The updater reconciles immutable-base LINE debt and otherwise only removes rows.
# Authority binds exact containing-line bytes at the immutable branch base;
# byte-identical lines may move within a source, but rewording is new debt.
# Prefer a symbol or file anchor; use a full-SHA #L permalink for historical
# evidence. Duplicate LINE rows are intentional multiplicity records.
#
# Regenerate with:
#   bash scripts/verify-doc-citations.sh -update
