# Authoritative list of directories the Trivy filesystem scan (the trivy-fs
# job in .github/workflows/security-scan.yml) skips.
# scripts/lib/trivy-skip-dirs.sh is the single shared derivation that reads
# THIS file; scripts/dev/trivy-fs-local.sh mirrors the same scan locally by
# sourcing that helper and calling the function it defines, not by reading
# this file directly, so both sides always skip the same set -- see
# go/internal/cigates/trivyskipdirs.go for the check that keeps them wired
# to it (specs/README.md, AGENTS.md).
#
# One directory per line, relative to the repository root. A line whose
# first non-whitespace character is '#' is a WHOLE-LINE comment (leading
# whitespace before that '#' is fine on a comment line); blank lines are
# ignored. A directory entry, by contrast, must have: no leading or
# trailing whitespace; no '#' anywhere in the entry -- put rationale on its
# own comment line above the entry instead, since there is NO trailing- or
# mid-entry-comment support; no comma (the shared derivation joins entries
# with ','); no glob metacharacter ('*', '?', '[', ']', '{', '}' -- a
# literal path is required, not a pattern); it must not normalize to the
# catch-all '.' (it would disable the scan's coverage entirely) or to '' (a
# slash-only entry such as '/' -- trivy's path matcher can never match an
# empty pattern against a real repo-relative file, so this skips nothing and
# is dead weight, not a catch-all) or a path escaping the repository root
# ('..', or anything starting '../');
# and it must not itself be an absolute path (a leading '/'). No entry may
# repeat. go/internal/cigates (checkTrivySkipDirsParity) rejects the whole
# file at drift-check time if any of the above is violated.
# Order is preserved verbatim when this file is joined into the
# --skip-dirs argument, but Trivy itself does not care about order.
